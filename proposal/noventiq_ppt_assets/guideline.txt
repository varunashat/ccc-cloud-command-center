[Slide 6 - Section Divider] 02 Brand essentials
[Slide 7 - Headline + Subheader + Text] Brand colours / Use only these colours — the layouts already apply them / Navy is the primary colour: headlines and key shapes; Cyan is the accent: numbers, lines and highlights; Light blue fills cards and boxes behind text; Red appears only inside the logo — never in text or shapes; The Office colour picker shows default theme colours: apply brand colours via More Colours > Hex / Navy; #0A408B · Headlines, key shapes / Dark navy; #0C2345 · Dark backgrounds / Cyan; #25AADD · Accents, numbers / Light blue; #EEF8FF · Card fills / Grey; #B7BAC2 · Outlines, dividers / Red; #E31D22 · Logo only / 7
[Slide 8 - Picture + Details] Typography / Fonts and sizes are set in the master — never change them / Headline / Montserrat ExtraBold, 40 pt, navy / Subheader / Montserrat, 20–22 pt, navy (cyan on dark); One line that states the key message / Body text / Tahoma, 12–14 pt, black (white on dark); Max. 6 bullets, one idea per bullet / Numbers / Montserrat, cyan: agenda, steps, KPIs; Use sentence case everywhere; avoid ALL CAPS / Aa; Montserrat ExtraBold; Headlines; Aa; Montserrat; Subheaders and numbers; Aa Tahoma — body text / 8
[Slide 9 - Dark – Headline + Subheader] Logo & imagery / The logo is placed by the layouts — never add it by hand / Never copy, move, resize or recolour the logo; Dark layouts carry the white logo; light layouts carry the colour logo; Keep the footer “Seven Seas Technology” and slide number untouched; On the closing logo slide, change nothing / Imagery rules; High-resolution photos only — no pixelation or stretching; Cool blue and dark tones that match the brand gradients; Simple line icons in navy, cyan or white; No clip art, emoji, WordArt or 3D effects; Insert pictures into picture placeholders so they crop to the layout / 9
[Slide 10 - Section Divider] 03 Building your deck
[Slide 11 - Six Numbered Points] Build a slide in 6 steps / From blank to on-brand in under a minute / 1 / Start from this template file — never from a blank or an old deck / 2 / Click Home > New Slide and pick the layout that fits your content / 3 / Click into each placeholder and type; keep headlines to one line / 4 / Paste with Ctrl+Shift+V (keep text only) so brand fonts stay intact / 5 / Delete placeholders you don’t use instead of leaving them empty / 6 / Check View > Slide Sorter: logo, footer and numbers on every slide / 11
[Slide 12 - Two Numbered Lists] Do's and don'ts / Quick rules that keep every deck on-brand / Do / Don't / 1 / Use the layouts exactly as provided / 2 / Keep one key message per slide / 3 / Use brand colours from the palette only / 4 / Align content to the placeholders / 5 / Use sentence case for headlines / 6 / Keep body text at 12 pt or larger / 1 / Move, resize or recolour the logo / 2 / Change fonts or add new ones / 3 / Use the Office default theme colours / 4 / Stretch, distort or pixelate images / 5 / Put more than 6 bullets on a slide / 6 / Add shadows, WordArt or 3D effects / 12
